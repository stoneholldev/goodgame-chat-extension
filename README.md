# GoodGame расширение для чата (Twitch like)

## ЗАГРУЗКА
1. Загрузить архив https://github.com/stoneholldev/goodgame-chat-extension/archive/refs/tags/1.0.zip
2. Распаковать

## УСТАНОВКА. Из файла `.crx` (для Яндекс Браузера, Edge, Brave и др.)**

1. Откройте страницу расширений (`chrome://extensions` или `browser://extensions`) и включите **Режим разработчика**.
2. Перетащите файл `.crx` из релиза прямо в окно браузера и подтвердите установку.
3. !! Для канала DreakingDad на GoodGame . URL GoodGameBot указан по умолчанию. Если нет, укажите - 
https://nonformal-snarlingly-isela.ngrok-free.dev/api/commands
Иначе команды, команды-изображения не будут подгружаться

## Основные функции

### Подсказки для команд (начинаются с символа !)
Подсказки появляются сразу после `!`. Первая команда выделяется, а ввод букв сужает список. Выбрать подсказку можно мышью, Tab или стрелками и Enter. Если имя команды набрано целиком, обычный Enter отправляет её. В настройках доступны сортировка по своим вызовам, общей популярности из API и алфавиту. Личные счётчики хранятся в профиле Chrome и увеличиваются после отправки. Команды с `!` в сообщениях чата тоже кликабельны. При выборе команда копируется и вставляется в поле ввода. Уже набранные аргументы сохраняются. Сообщение отправляется штатной кнопкой или клавишей отправки GoodGame.

Оформление в стиле Twitch использует Inter 14 px, тёмный фон и более компактные строки. Лицензия шрифта находится в `fonts/OFL.txt`.

### Настройки окна
В настройках окна можно отдельно менять размеры GIF-смайлов и высоту строки.
Оба ползунка по умолчанию стоят на 80%. В оформлении в стиле Twitch это
даёт высоту строки 22 px, в обычном оформлении — около 29 px. Длинный текст
по-прежнему переносится.

### Кнопки рядом с чатом
Кнопка в нижней панели чата рядом с меню открывает картинки из команд. Для галереи API должен
вернуть `"tag": "img"` и прямую ссылку на изображение в `reply` или `image_url`.
Поле `uses` задаёт популярность (число или строка с целым числом).
Плитка вставляет основное имя команды в поле ввода чата.

Кнопка «Список команд» показывает команды из API, пример вызова из `example`
и текст ответа из `reply`. Оба окна можно перетащить за свободную область и изменить
их размер за нижний правый угол. Положение и размер сохраняются отдельно для
каждого окна в профиле Chrome.

В галерее поиск работает по именам и псевдонимам команд. В списке команд
он также ищет по тексту ответа. Щелчок вне окна закрывает его.

Ползунок «Размер картинок в чате» уменьшает изображения до 20% с сохранением
пропорций. На 100% используется обычный размер GoodGame.

### Цвета никнеймов
В настройках «Цвета по никнеймам» можно назначить личные цвета. Они имеют
приоритет над отдельными цветами стримера, модераторов и зрителей.
Переключатели API команд и сортировки, открытые на канале GoodGame, применяются
к этому каналу. В остальных вкладках можно изменить настройки по умолчанию.
URL API общий, его значение сохраняется при отключении команд на канале.

## API команд

URL GoodGameBot для канала DreakingDad указан по умолчанию. Если нет, укажите - 
https://nonformal-snarlingly-isela.ngrok-free.dev/api/commands
При добавлении, редактировании, удалении команд тело запроса автоматически меняется
Если у вас есть кастомный апи для команд, можете использовать данный пример
```json
{
  "commands": [
    "!баланс",
    { "name": "!бонус", "description": "Получить бонус" },
    { "name": "help", "description": "Список команд" }
  ]
}
```
